# TapPilot

Автокликер для Android для одиночных игр.

APK собирается автоматически при каждом изменении — смотрите раздел **Releases**.

1. Установите APK.
2. Откройте TapPilot, задайте интервал и нажмите «Включить в спец. возможностях».
3. Включите службу TapPilot. Появится прицел ◎ и кнопка ▶.
4. Перетащите прицел на нужное место и нажмите ▶.
